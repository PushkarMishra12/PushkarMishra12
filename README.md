### 🚀 About Me &amp; Core Strengths

I am a software engineer focused on building **ultra-fast, resilient web architectures**, **high-throughput asynchronous APIs**, and **intelligent systems**. My engineering approach balances low-latency backend design with clean, intuitive user interfaces and real-world AI deployment.

- 🌐 **Full-Stack Web & Scalable APIs**: Expert in designing asynchronous microservices using **FastAPI**, **Python**, and **Uvicorn**, paired with responsive, clean web frontends and real-time WebSocket pipelines.
- 🧠 **Computer Vision & Applied AI**: Experienced in training and deploying **YOLO** object detection models, satellite/aerial imagery analysis pipelines, and edge inferencing.
- 📡 **Autonomous Systems & Edge Telemetry**: Developed robust UAV/drone communication uplinks, sensor telemetry feeds, and live mission-control command interfaces.
- ⚡ **Engineering Rigor**: Passionate about clean architecture, strict typing, asynchronous concurrency, and production-grade reliability.
